One line, at most 140 characters: the funniest single-line resignation letter — a zookeeper quits because the penguins have unionized. An AI judge compares lines two at a time and picks the funnier, fresher, tighter one.

The entry:

> Please accept my resignation: the zoo's penguins have unionized, and frankly, their demands are reasonable.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
